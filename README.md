# Employee Clock-In & Attendance Tracker

A web-based attendance management system built with **Laravel** and **PHP**. The application tracks employee check-ins/check-outs, calculates distance parameters, and provides dynamic data filtering for daily operations.

---

## 🚀 Features

* **Live Attendance Tracking:** Clock-in and clock-out functionality with real-time timestamps.
* **Distance & Location Verification:** Live distance calculation during clock-in.
* **Dynamic Data Filtering:** Easily filter attendance logs by dynamic date ranges.
* **Pagination & Search:** Clean data tables with built-in pagination for high-volume attendance records.
* **Responsive Dashboard:** Optimized for both desktop and mobile web screens.

---

## 🛠️ Tech Stack

* **Backend:** PHP, Laravel Framework, JavaScript
* **Frontend:** Blade Templates, CSS (Flexbox & Grid), JavaScript
* **Database:** MySQL
* **Tools:** Git, Composer, Artisan CLI
